# CS Study Streams Explained

## Question

What are the five streams within BSc Computer Science?

## Answer

BSc CS (JS1204) lets students specialise in one of five streams:

| Stream | Focus |
| --- | --- |
| Artificial Intelligence | machine learning, NLP, computer vision, generative AI |
| Cybersecurity | system/software security, cryptography, privacy |
| Data Science | data management, analytics, big data |
| Multimedia Computing | graphics, vision, VR, computer games |
| Software Engineering and Project Management | SE practice, testing, quality, project management |

A student typically commits to a stream by taking 3 courses of that stream (or takes any 5 electives for a mixed profile). This 'stream' model is a key differentiator: you get a broad CS degree plus a declared specialisation, which is easier for employers to read than a generic 'CS' title.
