# CS Core Courses Explained

## Question

What are the core CS courses and why do they matter?

## Answer

The core courses form the technical spine of the degree. From the programme and catalogue pages, representative core/foundational courses include: CS1302A/CS2310 Computer Programming, CS2115 Computer Organisation, CS2116 Computer Systems, CS2066 IT Professionals and Society, CS2402 Introduction to Computational Probability Modeling, and (further in the degree) CS3103 Operating Systems, CS3201 Computer Networks, CS3334 Data Structures, CS3342 Software Design, CS3343 Software Engineering Practice, CS3402 Database Systems, and CS4335 Design and Analysis of Algorithms.

These are what make a CS graduate employable: programming fluency, understanding of how computers are organised, data structures and algorithms, operating systems, networks, databases and software engineering. The core is shared across the streams; the streams then add depth in one area.
