# Institutional Scholarships for Non-JUPAS Entrants

> [!tip] Short answer
> Local non-JUPAS entrants (high-school 2027 graduates) in non-flagship programmes, e.g. JS1204 (1561A): GCE A-Level 4A* or IB >= 41 => HK$69,000/yr; 2A*+1A or IB 38-40 => HK$59,000/yr; 1A*+2A or IB 36-37 => HK$35,000/yr - each with one-off HK$25,000 exchange scholarship.

## Question

What entrance scholarship can a local non-JUPAS IB / A-Level student get for BSc Computer Science (1561A)?

## Answer

Local non-JUPAS entrants graduating from high school in 2027 and admitted to **any programme except the ten flagship ones** (so including **BSc Computer Science, code 1561A**) are eligible for the Institutional Scholarships on these criteria:

| Criteria (GCE A-Level / IB Diploma incl. bonus points) | Value per annum | Exchange scholarship |
|---|---|---|
| 4A*  /  IB >= 41 | **HK$69,000** | HK$25,000 (one-off) |
| 2A* + 1A  /  IB 38-40 | **HK$59,000** | HK$25,000 (one-off) |
| 1A* + 2A  /  IB 36-37 | **HK$35,000** | HK$25,000 (one-off) |

Same rules as the JUPAS version: **all scores in one sitting**, repeat subjects not counted, two AS = one A-Level, the same subject not counted at both levels, **GCE Chinese not counted**, and non-flagship-only (an ACT/1070 entrant uses the Flagship tier instead). Tenable for 4-6 years (4 for JS1204), renewed on CGPA. No application required.

## Examples

- A local A-Level student admitted to JS1204 (1561A) with 4A* (e.g. Maths, Further Maths, Physics, ICT) receives HK$69,000/yr x 4 + HK$25,000 one-off exchange scholarship.
- The same student admitted to ACT (1070) with 4A* would instead receive the Flagship **full** scholarship (100% tuition + hall fees) - worth comparing when choosing between the two programmes.
