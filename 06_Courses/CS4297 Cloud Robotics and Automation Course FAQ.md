# CS4297 Cloud Robotics and Automation Course FAQ

> [!tip] Short answer
> **CS4297 Cloud Robotics and Automation** is a CityUHK CS undergraduate course in the Core / Foundational area (?-series, typically the degree of the degree).

## Question

What is the CityUHK CS course CS4297 (Cloud Robotics and Automation) and where does it fit?

## Answer

**CS4297 Cloud Robotics and Automation** is a CityUHK Department of Computer Science undergraduate course in the Core / Foundational area: Robotics and automation on cloud infrastructure.

Course levels in CityUHK CS follow the digit convention: 1000-series = first year, 2000-series = second year, 3000-series = third year, 4000-series = fourth year. This course is a **?-series** course, so it is typically taken in **the degree** of the degree.
