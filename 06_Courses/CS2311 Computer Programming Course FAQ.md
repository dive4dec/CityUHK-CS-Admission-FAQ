# CS2311 Computer Programming Course FAQ

> [!tip] Short answer
> **CS2311 Computer Programming** is a CityUHK CS undergraduate course in the Programming area (?-series, typically the degree of the degree).

## Question

What is the CityUHK CS course CS2311 (Computer Programming) and where does it fit?

## Answer

**CS2311 Computer Programming** is a CityUHK Department of Computer Science undergraduate course in the Programming area: Programming core (track variant).

Course levels in CityUHK CS follow the digit convention: 1000-series = first year, 2000-series = second year, 3000-series = third year, 4000-series = fourth year. This course is a **?-series** course, so it is typically taken in **the degree** of the degree.

## Examples

- If this course appears in your chosen stream's elective list, taking 3 courses of the same stream (or 5 mixed electives) is how you commit to a specialisation in BSc CS (JS1204).
