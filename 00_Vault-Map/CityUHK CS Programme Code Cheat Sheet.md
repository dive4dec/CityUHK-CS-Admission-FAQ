# CityUHK CS Programme Code Cheat Sheet

> [!tip] Short answer
> JUPAS: JS1204 BSc CS, JS1218 Cybersecurity, JS1221 double degree. Non-JUPAS: 1561A/1720A/1715A/1718A - application fee HK$200 per programme; senior-year (ASII) admission is local-only.

## Question

Which JUPAS and non-JUPAS codes correspond to the CS programmes?

## Answer

| Code | Programme | Route |
| --- | --- | --- |
| JS1204 | BSc Computer Science (5 streams) | JUPAS |
| JS1218 | BSc Cybersecurity | JUPAS |
| JS1221 | BSc CS + BSc Computational Finance & FinTech (double degree) | JUPAS |
| JS1071 | Data Science (Majors: BSc DS / BSc DSE) | JUPAS |
| JS1072 | BSc Data Science | JUPAS |
| JS1074 | BSc Data and Systems Engineering | JUPAS |
| JS1070 | AI, Computing and Transformation (ACT) | JUPAS |
| 1561A | BSc Computer Science | Non-JUPAS Year 1 / ASI |
| 1720A | BSc Cybersecurity | Non-JUPAS Year 1 / ASI / ASII |
| 1715A | BSc Data Science | Non-JUPAS Year 1 / ASI |
| 1718A | BSc Data and Systems Engineering | Non-JUPAS Year 1 / ASI |



Non-JUPAS application fee is HK$200 per programme. Senior-year (ASII) admission is only for local students.
