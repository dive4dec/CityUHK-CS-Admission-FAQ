# Where to Find the Official Documents Cited in This Vault

> [!tip] Short answer
> Every figure traces to a public PDF on cityu.edu.hk/admo, jupas.edu.hk and cs.cityu.edu.hk. Each note in the vault carries a Source line naming its specific document.

## Question

Where are the primary sources for all these numbers?

## Answer

- JUPAS score formula & admissions scores (2026): cityu.edu.hk/admo/sites/default/files/2026-01/2026_JUPAS_AdmissionScoreFormulaAndScores.pdf

- JUPAS flexible admission thresholds (2026): cityu.edu.hk/admo/sites/default/files/2026-05/2026_JUPAS_FlexibleAdmissionThresholdScore.pdf

- Prior-year score reports: 2023, 2024, 2025 equivalents on the same admo file server.

- JUPAS 2027 key dates: jupas.edu.hk (Application Key Dates and Deadlines V1.1).

- Non-JUPAS leaflet: cityu.edu.hk/admo/sites/default/files/2024-10/2025_Undergraduate_Admissions-NON-JUPAS.pdf

- 9-institution JUPAS scores (all universities): jupas.edu.hk/f/page/3667/ (af_2023/2024/2025_JUPAS.pdf).

- CS programme pages: admission.cs.cityu.edu.hk and cs.cityu.edu.hk.

All notes in this vault carry a Source line pointing to the specific document.
